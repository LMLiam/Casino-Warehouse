# Code of Conduct

Casino Warehouse should be a welcoming project for contributors, players, testers, and maintainers.

## Expected Behaviour

- Be respectful and constructive.
- Assume good intent while still being clear about bugs and risks.
- Keep discussions focused on the project.
- Give actionable feedback in issues and pull requests.
- Respect maintainer decisions about scope, licensing, and release direction.

## Unacceptable Behaviour

- Harassment, threats, insults, or discriminatory language.
- Personal attacks or repeated hostile comments.
- Publishing private information without permission.
- Spam, trolling, or intentionally derailing project discussions.
- Pressuring maintainers to accept commercial use or license exceptions in public threads.

## Enforcement

Maintainers may edit, hide, lock, or delete comments; close issues or pull requests; block users; or report behaviour to GitHub when needed.

If you need to report a conduct issue, contact the project owner privately through GitHub.
