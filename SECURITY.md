# Security Policy

Casino Warehouse is a fictional-money demo game. It is not production gambling software, does not handle real payments, and does not store real-money balances.

## Supported Versions

Security reports are accepted for the current `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for sensitive security reports.

Report vulnerabilities privately to the project owner through GitHub. Include:

- A concise description of the issue.
- Steps to reproduce.
- Affected files, endpoints, or workflows.
- Expected impact.
- Any suggested fix or mitigation.

## Scope

In scope:

- Vulnerabilities in the app code.
- Unsafe defaults that expose local data unexpectedly.
- Dependency or build configuration issues that affect this project.

Out of scope:

- Real-money gambling compliance, because this project has no real-money flow.
- Attacks requiring local machine access beyond the app's demo data.
- Reports against third-party services unless the issue is caused by Casino Warehouse configuration.
